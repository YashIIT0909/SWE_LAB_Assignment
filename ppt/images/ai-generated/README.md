# Illustrations you can add (optional)

Put transparent-background PNGs here with exactly these names. The deck looks complete without them;
each one is used only if the file exists. Slide numbers refer to `PPT_Modify.md`.

Make all of them in one session so the style matches. **Start every prompt with this style line:**

> Flat vector illustration, soft rounded shapes, gentle shadow, deep teal (#0B3C49 and #1F7A8C) with
> warm amber (#F4A62A) accents, clean minimal, no text, no letters, no logos, transparent background.

Export PNG with a transparent background (remove the background if the tool cannot), at least 1600 px on
the long side.
